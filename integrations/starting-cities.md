# Starting cities and staged city launches

Character setup is headed China and shows only cities enabled under Admin → Cities. Both inside-China and outside-China players choose a starting city. Students choose a campus available in that city, keep that city in their profile and introduction, and can change campus from their profile. Existing Shenyang student stories and temporary campus profiles are preserved.

Admin can switch Shenyang off and open other supported cities individually. At least one city must stay open. With no stored admin configuration China is the default. The explicitly invoked launch command switches the existing open list to China once without moving existing characters. A first cloud save rejects a closed starting city. Existing characters can still save their progress in a city that admin subsequently closes, but closed cities cannot be selected as new starting cities or travel destinations.

This uses the existing open_cities setting; no native app rebuild is needed. After deployment, run `php /www/wwwroot/hafrik.com/api/v4/chinalife/migrate.php` then `php /www/wwwroot/hafrik.com/api/v4/chinalife/activate-china.php`. The second command opens only China once, storing the previous open list in the china_hub_launch setting. Repeating it preserves later admin changes. It does not move or reset old characters. China is now a playable starter area with the shared game venues, HQ, services, elections, student campuses, businesses and nightlife. Named cities remain available for admin to unlock later. Existing players can use Travel → China for free; their old save, wallet, inventory and property progress are kept. Public Hafrik listings and partner listings assigned to closed cities are surfaced in China without editing their stored source or placement. Opening a named city restores its dedicated placement view.

The election screen adds office tabs, username/campaign search and real vote totals/percentages on candidate cards. Existing office types, private ballots, one-vote enforcement and own-campaign sharing are retained. No Police/Court system, national office, cabinet, account-age voting restriction or fictional vote counts are introduced. Those require a separate rules/design decision.
